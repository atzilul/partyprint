# מצב גישה וביצוע לאחר חיבור Search Console
עדכון: 1 בנובמבר 2026. המסמך מתעד גישה, מקורות ושערי עבודה. נתוני התנועה והשאילתות עצמם נמצאים בחבילת הדוח הפרטית ולא ב-Git.

## אימות שבוצע
- Windsor החזיר שני מקורות רלוונטיים ונבחרו נכסי PARTYPRINT בלבד.
- Search Console: https://partyprint.co.il/ (URL-prefix).
- GA4: PARTYPRINT | partyprint.co.il, property 560706114, stream 16206966493, Measurement ID G-V3QDR0W4WK.
- metadata מהמקור החי תאם hostname=partyprint.co.il ו-timezone=Asia/Jerusalem.
- שליפות נתונים הסתיימו בהצלחה. D01 ו-D02 אינם חסומים עוד ואין צורך לבקש חיבור מחדש.

## כיסוי ובקרה
נדרש חלון 1.8–29.10.2026. הוחזרו ימי GSC ב-20.9–29.10 וימי GA4 ב-27–29.10; אין היסטוריה מלאה לכל 90 הימים.
GSC נשלף בלי נתונים טריים שאינם סופיים. 30–31.10 ב-GA4 נקראו בנפרד וסומנו כימים קרובים שעשויים להשתנות.
מועדי GSC הם Pacific Time ו-GA4 לפי Asia/Jerusalem; אין ייחוס שאילתה לאדם או הצלבה סיבתית לפי יום.
מגבלות פרטיות/החזרת שורות ואגרגציה נכס מול עמוד מתועדות. תוצאות שאילתות אינן בהכרח כל השאילתות.
