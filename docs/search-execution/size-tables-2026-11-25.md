# Q07 (המשך) — טבלאות מידות למבוגרים ולילדים במדריך המידות (2026-11-25)

## מקור

סעיף 3 בשאלון עובדות העסק: טבלת בית הדפוס בסנטימטרים, נמדד על חולצה פרושה,
סטייה של עד 5% אפשרית. מבוגרים בגזרה אחת S עד XL; ילדים לפי גיל 2 עד 18.

## מה השתנה

- `lib/size-chart.ts`: שתי הטבלאות כברירת מחדל בקוד. טבלת המבוגרים מוחלפת
  בטבלה שמוגדרת בפאנל הניהול (תוכן האתר → מידות) כשיש כזו; טבלת הילדים קבועה.
- מדריך המידות (`SizeGuide` ב-`app/order-experience.tsx`, מופיע בחלון המידות
  בטופס ובעמוד התודה): שני לשוניות "מבוגרים · S עד XL" ו"ילדים · לפי גיל",
  איור חולצה עם סימוני רוחב ואורך, טבלה עם כותרת, הערת הסטייה והגיל, וקישור
  WhatsApp לעזרה. ההסבר המילולי הישן הוחלף.
- שאלות ותשובות בבית: "לא בטוחים במידות, במיוחד לילדים?" מפנה לטבלאות ול-WhatsApp.
- תרגום ל-ar/en/ru: 19 משפטים חדשים לכל שפה; `check-translations` 0 בעיות,
  מבחן השער עובר.
